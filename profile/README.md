# Mylabella

## Intelligent tools for work in the real world

Mylabella explores and builds practical systems at the intersection of
artificial intelligence, automation, engineering software, and self-hosted
infrastructure.

The goal is not AI for its own sake. It is software that helps people understand
complex systems, make better decisions, and move safely from an idea to a
working result.

## What we work on

- **AI-assisted engineering** — connecting language models with professional
  tools and structured technical workflows.
- **Local-first AI** — agents, retrieval, and automation that can run close to
  the data they use.
- **Connected systems** — software that observes and acts on physical or
  operational environments.
- **Reliable product foundations** — reusable architecture, documentation,
  security, and delivery practices for maintainable digital products.

Projects are published when their documentation, security boundaries, and
maintenance expectations are clear enough for public use. Each repository
describes its own maturity and support level.

## Principles

- Start from a real user or operational outcome.
- Prefer understandable systems over unnecessary complexity.
- Keep humans accountable for AI-assisted decisions and changes.
- Treat privacy, security, reversibility, and documentation as design inputs.
- Make public work reusable under an explicit license.

## Contributing

Contributions can include code, documentation, testing, examples, design
feedback, and reproducible bug reports. Start with the README and contribution
guide in the relevant repository, then see our organization-wide
[`CONTRIBUTING.md`](https://github.com/Mylabella/.github/blob/main/CONTRIBUTING.md).

For usage questions, bug reports, feature proposals, and security concerns,
follow the routing in [`SUPPORT.md`](https://github.com/Mylabella/.github/blob/main/SUPPORT.md).
